# Auturis

Auturis is a system for thinking through moral decisions, built on Kant's
moral philosophy. It is for someone who already thinks seriously about their
own choices and has a problem against which they would like to test that
thinking.

It works on two questions:

- **What should I do?** It helps you state precisely what you propose to do
  and why, then asks what would happen if everyone acted on that principle,
  and how it fits with the rest of what you care about.
- **What is right?** For groups and organizations, it reports what a proposed
  rule does to each affected party's recorded pursuits.

It presses; it does not decide. You may find what it has to say truly
informative, or it may tell you something you already knew, in which case
you will have further support for your decision.

## Getting it

Auturis runs as a desktop app on Mac and Windows. It adds a graph of your
commitments, built up over time, and Decide, which weighs your options
against it. It is in a closely managed beta, available on request at
[auturis.com](https://auturis.com). It uses your own API key;
[step-by-step instructions](https://auturis.com/key).
